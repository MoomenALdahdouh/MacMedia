# Security

MacMedia is a local media player. It does not phone home.

## Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/MoomenALdahdouh/MacMedia/security/advisories/new) for anything that could crash the app, execute untrusted files, or leak local data. Do not open a public issue for that class of report.

## Scope

In scope: the MacMedia app, packaging scripts, and bundled libraries as shipped in a GitHub Release.

Out of scope: DRM circumvention, playing store-protected content, and third-party mpv/FFmpeg bugs that are already public upstream.
